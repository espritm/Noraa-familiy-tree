# Features

## Initial release

### Access

- application available under `/familiy-tree`;
- authentication required before any private data is loaded;
- sessions expire after a configurable duration;
- explicit sign-out control.

### Interactive tree

- free panning in both axes;
- zoom using a mouse wheel, trackpad, pinch gesture, and accessible controls;
- recenter control and return to the starting person;
- select any person as the new centre;
- visually distinct links for parentage and partnerships;
- progressive loading or virtualised rendering for large families.

### People and relationships

- one or more given names;
- birth name and customary name;
- birth date and place;
- death date and place;
- primary photograph shown in the tree;
- photograph and document gallery in the profile;
- parents, children, partnerships, and siblings;
- biographical notes and linked sources.

### Search

- case-insensitive and accent-tolerant search;
- search by given name, surname, place, and year;
- select a result and recenter the tree.

### Administration

- create and edit people;
- manage relationships without introducing invalid cycles;
- upload media with captions, dates, and sources;
- retain a minimal change history;
- export and back up private data.

## Potential improvements

- chronological view of family events;
- map of births, marriages, residences, and deaths;
- cross-family photograph and document gallery;
- curated narratives about a branch or person;
- duplicate detection suggestions;
- GEDCOM import and export after validating the internal model;
- correction proposal workflow requiring approval;
- assisted transcription of scanned documents, always reviewed by a person.

## Outside the initial scope

- a family social network;
- anonymous editing;
- automatic publication of information about living people;
- storage of high-resolution originals on GitHub.
