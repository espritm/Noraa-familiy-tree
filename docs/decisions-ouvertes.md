# Décisions ouvertes

## Hébergement

- type exact de l'offre OVH et accès disponibles : FTP/SFTP, SSH, base de données, tâches planifiées, configuration du serveur ;
- contenu actuel de WordPress et nécessité de le conserver ;
- possibilité technique de servir une application sous `/familiy-tree` ;
- mécanisme de sauvegarde déjà fourni par OVH.

## Produit

- personne ou couple affiché au centre lors de la première ouverture ;
- sens initial de l'arbre : ascendants, descendants ou vue mixte ;
- nombre estimé de personnes et de médias ;
- règles d'affichage applicables aux personnes vivantes ;
- personnes autorisées à administrer ou proposer des corrections ;
- langues nécessaires.

## Données

- qualité et format des scans disponibles ;
- existence d'un fichier GEDCOM ou d'un arbre numérique antérieur ;
- conventions employées dans les notes pour les dates incertaines et les sources ;
- emplacement privé retenu pour les originaux et sauvegardes.

## Identité visuelle

- logo éventuel, couleurs, typographies et ambiance souhaitée ;
- photographies ou documents pouvant être utilisés avec consentement dans l'interface finale.
