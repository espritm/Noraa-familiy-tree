# Archive digitisation and import

## Goal

Convert more than one hundred pages of handwritten research into structured data without losing provenance, nuance, or uncertainty.

## Recommended process

1. Number the physical pages before scanning.
2. Scan or photograph each page flat, with even lighting and readable quality.
3. Retain a private high-resolution original and create a working copy.
4. Transcribe each page manually or with OCR assistance.
5. Review the transcription against the original image.
6. Extract people, relationships, events, places, and archival references.
7. Explicitly mark uncertain readings and contradictions.
8. Ask the original researcher to validate reconciliations and corrections.
9. Import first into a private review dataset.
10. Create a backup before every bulk import.

## Tracking convention

Each page receives a stable identifier such as `NOTE-0001`. Every extracted fact retains this identifier and, when practical, the relevant line or region. An archival source mentioned on the page is recorded separately from the note page itself.

## Quality control

- double-check names, dates, and parentage links;
- distinguish observed text, interpretation, and hypothesis;
- detect potential duplicates but require human confirmation;
- report incompatible events;
- review a sample after each import batch;
- never add a real document to the public repository.

## Exchange format

A private spreadsheet template may support initial data entry, with separate sheets or files for people, relationships, events, and sources. GEDCOM may be used for interoperability, but it may not represent sources, media, and uncertainty with the required level of detail.
